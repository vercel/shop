Vercel Shop ships a complete storefront on top of Shopify. Each feature below is built in and ready to customize. Start from a page type or component and follow it into the code.

## Storefront

  <Card title="Cart" href="/docs/anatomy/cart">

  </Card>
  <Card title="Navigation" href="/docs/anatomy/navigation">

  </Card>
  <Card title="Footer" href="/docs/anatomy/footer">
    Policy links, social links, and optional Shopify menu columns.
  </Card>
  <Card title="Shopping assistant" href="/docs/anatomy/agent">
    AI-powered product discovery and cart management.
  </Card>
  <Card title="Authentication" href="/docs/anatomy/authentication">

  </Card>
</Cards>
