The storefront can publish a Universal Commerce Protocol (UCP) business profile at `GET /.well-known/ucp`. Agents use this machine-readable document to discover the store’s supported commerce services, capabilities, transports, and endpoints.

The integration is disabled by default. When disabled, `GET /.well-known/ucp` returns `404`.

## Enable the business profile

Set `ucp.isEnabled` to `true` in `lib/config.ts`, then deploy the storefront. The route fetches Shopify’s generated business profile for `NEXT_PUBLIC_SHOPIFY_STORE_DOMAIN` and serves it from the storefront domain.

The route preserves Shopify’s response status and forwards its validation headers (`etag`, `last-modified`, `vary`). It applies edge-first caching: a successful profile is cached on Vercel’s CDN for 60 seconds, served stale for up to 5 minutes while it revalidates in the background, and served stale for up to 24 hours if Shopify is unreachable. Errors and the not-published `404` are never cached. If Shopify returns `404`, browser requests render the storefront’s not-found page while agent requests receive Shopify’s machine response. The route does not redirect agents to Shopify or maintain a separate profile.

Shopify controls which capabilities appear in the profile. Enable and configure supported agentic commerce features in Shopify admin rather than editing the route response.

After deployment, fetch `/.well-known/ucp` from the storefront domain. Confirm that the response contains the expected services and capabilities and that its endpoints match the Shopify store.

## What’s next

Agents can use the advertised endpoints to negotiate and access supported commerce flows. Recheck the deployed profile after changing agentic commerce settings in Shopify.
