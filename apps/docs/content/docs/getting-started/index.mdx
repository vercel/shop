Connect a Shopify store, then run Vercel Shop locally or deploy it to Vercel.

## Prerequisites

You need:

- Node.js 24
- [pnpm](https://pnpm.io) for installing dependencies and running scripts
- A Shopify store

## 1. Configure Shopify store

Install Shopify's [Headless sales channel](https://apps.shopify.com/headless), create a new storefront in the Headless channel app in your Shopify admin, and copy its **Storefront API access token**. Grant the required [Storefront API permissions](/docs/reference/storefront-api-permissions). For the full walkthrough, see [Setup Shopify](/docs/getting-started/shopify-setup).

<Callout type="note" title="Stores from the Vercel Marketplace">
  If you created your store through the [Vercel Marketplace Shopify
  integration](https://vercel.com/marketplace/shopify), you have the **Vercel Storefronts** channel
  instead of **Headless**. Manage the storefront and its access token there.
</Callout>

## 2. Create your project

```bash
npx create-vercel-shop@latest my-store
cd my-store
```

## 3. Add your credentials

Create `.env.local` in the project root:

```bash
NEXT_PUBLIC_SHOPIFY_STORE_DOMAIN="your-store.myshopify.com"
NEXT_PUBLIC_SHOPIFY_STOREFRONT_ACCESS_TOKEN="shpat_1234567890abcdefghijklmnopqrstuvwxyz"
```

Find `NEXT_PUBLIC_SHOPIFY_STORE_DOMAIN` under [Settings → Domains](https://help.shopify.com/en/manual/domains) in Shopify admin. Find `NEXT_PUBLIC_SHOPIFY_STOREFRONT_ACCESS_TOKEN` in the [Headless channel storefront](https://shopify.dev/docs/storefronts/headless/building-with-the-storefront-api/manage-headless-channels).

<Callout type="note" title="Customer login needs more setup">
  Customer accounts require additional credentials and configuration. See
  [Authentication](/docs/anatomy/authentication) before enabling sign-in.
</Callout>

See [Environment Variables](/docs/reference/env-vars) for optional settings.

## 4. Run the storefront

```bash
pnpm dev
```

Open [localhost:3000](http://localhost:3000) and confirm that your Shopify products appear.

If no products appear, you may still need to publish products to the Headless channel. See [publishing products to your storefront](/docs/getting-started/shopify-setup#publish-products-to-your-storefront).

## 5. Deploy to Vercel

When you're ready to deploy, commit and push your changes to your Git repository. Then import the project at [vercel.com/new](https://vercel.com/new), or use the CLI:

```bash
pnpm add -g vercel
vercel
```

Add the required [environment variables](/docs/reference/env-vars) to the Vercel project before your first production deploy. Stores created through the [Vercel Marketplace Shopify integration](https://vercel.com/marketplace/shopify) have their Shopify credentials configured for you.
