Vercel Shop is an enterprise-ready Shopify storefront built with Next.js. Shopify runs your catalog, checkout, and payments. Vercel Shop gives you the storefront in front of them: product pages, collections, search, and a cart, all backed by the Shopify Storefront API and ready to customize.

You get the storefront as source in your own repository. Read it, change it, and extend it with your team or a coding agent, then deploy it to Vercel.

## What you get out of the box

Going headless usually means rebuilding the same foundation before you can ship. Vercel Shop includes that foundation:

- Product, collection, and search pages backed by the Shopify Storefront API.
- A server-backed cart and checkout handoff to Shopify.
- Navigation and footer, with optional Shopify-managed menus.
- SEO, sitemaps, and structured data for product and collection pages.
- Machine-readable content for AI answer engines. See [AEO and GEO](/docs/anatomy/aeo-geo).
- Webhook-driven revalidation, so edits in Shopify Admin refresh the storefront.
- Optional customer accounts and an AI shopping assistant.

## Enterprise-ready

- **Scale.** Static generation, streaming, and caching on Vercel handle traffic spikes and large catalogs.
- **Security.** Shopify owns checkout and payment data. Customer sessions are encrypted, and API secrets stay server-side.
- **Composability.** The storefront is a standard Next.js app talking to Shopify's APIs, so you add features, services, and integrations in your own codebase.

## Built for agentic development

Vercel, Shopify, and third-party partners maintain skills and embedded docs so coding agents extend the storefront correctly. Skills carry task-specific instructions and checks, and the repository ships `AGENTS.md` conventions so an agent follows the same patterns your team does. See [Extending with Agents](/docs/getting-started/extending-with-agents).

## Two ways to start

- **Base template.** The starting point for development. It ships the commerce foundation with room to build on top. `create-vercel-shop` scaffolds it. Start with [Getting Started](/docs/getting-started).
- **Enterprise demo.** A production-shaped example with agentic features, subscriptions, and more already enabled. See it live at the [enterprise demo](https://shop-template-git-demo-enterprise.labs.vercel.dev/).

## Part of the new Hydrogen

Vercel is a design partner on the rebuild of [Shopify Hydrogen](https://vercel.com/blog/vercel-and-shopify-are-rebuilding-hydrogen), Shopify's storefront toolkit, redesigned with the Next.js team to be framework- and runtime-agnostic. Vercel Shop is the Next.js template for Shopify and Hydrogen going forward. As Hydrogen stabilizes, Vercel Shop adopts it and stays the reference for building Shopify storefronts with Next.js.

## Why teams choose Vercel Shop

- Open source and maintained by Vercel. Track upstream improvements and roll them into your storefront with the [`update-shop` skill](/docs/skills/update-shop).
- Vercel builds and maintains Next.js, so the framework and the template move forward together.
- Shopify features and third-party integrations arrive as maintained skills, so a coding agent adds them the same way every time.
- The storefront is yours as source. Extend it in your own codebase instead of waiting on a vendor roadmap.

The code is open source. Read it and file issues at [github.com/vercel/shop](https://github.com/vercel/shop).
