## Pages

| Route                                 | Description                                                   |
| ------------------------------------- | ------------------------------------------------------------- |
| `/`                                   | Home page                                                     |
| `/products/[handle]`                  | Product detail page; option query parameters select a variant |
| `/collections`                        | Collection index                                              |
| `/collections/[handle]`               | Collection listing with filters, sorting, and pagination      |
| `/collections/all`                    | All-products listing                                          |
| `/search`                             | Product search results                                        |
| `/cart`                               | Cart and related products                                     |
| `/blogs/[blogHandle]`                 | Shopify blog listing                                          |
| `/blogs/[blogHandle]/[articleHandle]` | Shopify article                                               |
| `/pages/[handle]`                     | Shopify page                                                  |
| `/policies/[handle]`                  | Shopify store policy                                          |

## API routes

| Route                        | Description                                                                 |
| ---------------------------- | --------------------------------------------------------------------------- |
| `POST /api/webhooks/shopify` | Shopify webhook handler for cache invalidation                              |
| `POST /api/chat`             | Shopping-assistant stream; returns `404` unless `agent.isEnabled` is `true` |
| `GET /api/cart`              | Current cart                                                                |
| `POST /api/cart`             | Cart creation and updates                                                   |
| `GET /api/predictive-search` | Search suggestions                                                          |

Cart and predictive-search endpoints are handled by Shopify Hydrogen through the storefront proxy.

## Customer accounts

These routes require `auth.isEnabled` and the [authentication credentials](/docs/reference/env-vars#customer-authentication). Account pages require sign-in.

| Route                    | Description                                            |
| ------------------------ | ------------------------------------------------------ |
| `/account`               | Redirects to `/account/profile`                        |
| `/account/profile`       | Customer profile                                       |
| `/account/addresses`     | Saved addresses                                        |
| `/account/orders`        | Order history                                          |
| `/account/orders/[id]`   | Order details                                          |
| `GET /account/login`     | Starts customer sign-in                                |
| `GET /account/authorize` | OAuth callback                                         |
| `GET /account/refresh`   | Refreshes the customer session                         |
| `POST /account/logout`   | Signs the customer out; requires a same-origin request |

| Route                      | Description                         |
| -------------------------- | ----------------------------------- |
| `/robots.txt`              | Crawler rules                       |
| `/sitemap.xml`             | Sitemap index                       |
| `/sitemap/[shard]`         | Sitemap entries for a content group |
| `/llms.txt`                | Storefront guide for AI agents      |

The home, product, collection-detail, and search URLs also return Markdown when requested with `Accept: text/markdown`. See [Proxy](/docs/anatomy/proxy) for Shopify compatibility routes.

## Variant URLs

Product options use one query parameter per option. The key is the option name as defined in Shopify and the value is the selected option value.

Liquid-style links such as `/products/your-product?variant=123456789` redirect to the matching option-parameter URL.

For example, `/products/your-product?Color=Blue&Size=XS` selects the blue, extra-small variant. Option names and values are matched case-insensitively, so `?color=blue&size=xs` resolves to the same variant. Without option parameters, the page selects the first available variant.

Selecting an option on the same product keeps unrelated query parameters, such as campaign tags, in the URL.
