## Pages

| Route                                 | Description                                                   |
| ------------------------------------- | ------------------------------------------------------------- |
| `/`                                   | Home page                                                     |
| `/products/[handle]`                  | Product detail page; option query parameters select a variant |
| `/collections`                        | Collection index                                              |
| `/collections/[handle]`               | Collection listing with filters, sorting, and pagination      |
| `/collections/all`                    | All-products listing                                          |
| `/search`                             | Product search results                                        |
| `/cart`                               | Cart and related products                                     |
| `/blogs/[blogHandle]`                 | Shopify blog listing                                          |
| `/blogs/[blogHandle]/[articleHandle]` | Shopify article                                               |
| `/pages/[handle]`                     | Shopify page                                                  |
| `/policies/[handle]`                  | Shopify store policy                                          |

## Variant URLs

Product options use one query parameter per option. The key is the option name as defined in Shopify and the value is the selected option value. This matches the URLs a Liquid theme produces.

For example, `/products/your-product?Color=Blue&Size=XS` selects the blue, extra-small variant. Option names and values are matched case-insensitively, so `?color=blue&size=xs` resolves to the same variant. Without option parameters, the page selects the first available variant.

Selecting an option keeps unrelated query parameters, such as campaign tags, in the URL.
